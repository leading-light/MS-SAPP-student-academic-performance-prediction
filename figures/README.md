# MS-SAPP Research Figures and Visualizations

This directory contains the figures associated with the **MS-SAPP (Student Academic Performance Prediction)** framework. The visual materials are organized into two categories:

1. **Research Paper Figures:** Figures presented in the MS-SAPP research paper.
2. **Notebook-Generated Figures:** Visualizations generated during the execution of the research implementation.

## 1. Research Paper Figures

The `research_paper_figures/` directory contains the seven figures included in the MS-SAPP research paper.

These figures illustrate the proposed framework, experimental methodology, classifier rankings, consensus-based evaluation, predictive performance, feature configuration analysis, and classifier robustness.

The figures are provided as readily accessible visual references to the research methodology and findings.

## 2. Notebook-Generated Figures

The `notebook_generated/` directory documents the visualizations generated during the execution of the main MS-SAPP research implementation.

The experimental evaluation comprises:

- **6 datasets**
- **21 classifiers**
- **126 dataset–classifier experiments**
- **126 confusion matrices**

### Confusion Matrices

The 126 confusion matrices are computed and displayed by **Module 7** of the main research notebook. Each matrix represents the classification performance of a particular classifier on a particular dataset.

The complete set can be inspected by executing Module 7 in:

`src/St_Acd_Per_AutoML_Updated_Final.ipynb`

The `notebook_generated/confusion_matrices/` directory is reserved for individual confusion matrix image files if they are exported and saved separately by the implementation.

**Note:** The confusion matrices are displayed during notebook execution. They are not necessarily saved as individual image files automatically.

Refer to `notebook_generated/README.md` for further details.

## 3. Reproducibility and Usage

The research paper figures provide a visual summary of the proposed framework and its findings, while the notebook-generated visualizations offer detailed experimental outputs for further inspection.

Researchers can:

- Examine the research paper figures directly from this repository.
- Execute the main research notebook to reproduce the experimental visualizations.
- Inspect the 126 confusion matrices generated by Module 7.
- Refer to the `results/` directory for detailed experimental results.

For the complete implementation, datasets, dependencies, and experimental results, please refer to the main repository `README.md` and the corresponding project directories.

## 4. Main Implementation

The complete research implementation is available in:

`src/St_Acd_Per_AutoML_Updated_Final.ipynb`

The notebook contains the code used to conduct the experiments and generate the associated visualizations.
